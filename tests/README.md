# Tests

Esta carpeta contendra tests cuando existan piezas relevantes que merezcan proteccion.

No hay una suite de tests inicial porque todavia no existe codigo funcional que probar. Los tests se anadiran a medida que aparezcan componentes importantes.

Ejemplos futuros:

- metricas;
- congelacion de capas;
- acumulacion de gradientes;
- equivalencia del merge de LoRA;
- gradient checking;
- reproducibilidad;
- guardado y restauracion de checkpoints.

La prioridad inicial es aprender y escribir los experimentos con claridad. Los tests deben proteger piezas concretas, especialmente matematicas o comportamientos faciles de romper.
