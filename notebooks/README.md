# Notebooks

Esta carpeta se usara para estudiar conceptos, hacer pruebas exploratorias y crear visualizaciones.

Un notebook puede contener ideas incompletas, derivaciones paso a paso, graficas, comparaciones pequenas o codigo que todavia no esta preparado para ser reproducible.

## Exploracion frente a experimento

Un notebook sirve para entender.

Un script en `experiments/` sirve para repetir una ejecucion con una pregunta clara, configuracion visible, metricas guardadas y conclusiones.

Cuando un notebook deje de ser exploratorio y tenga una estructura estable, conviene convertirlo en un script de `experiments/`.
